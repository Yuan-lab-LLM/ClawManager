修复行为

  • 发布 assignment 后确认同一名称、UID、同类型 resourceVersion、身份和请求；库存未追上时保留 creating、SQL 认领及绑定，由已有持久 reconciliation 重观察；直接新建 G1 超过原始 CreatedAt 五分钟后显示 RUNTIME_PUBLICATION_TIMEOUT，保留身份与占用并阻止迟到启动。
  • 租约仅对明确的库存暂态错误做有界整组重试，每次重新验证完整身份与实际 TCP 来源，不返回部分凭证。
  • UID、generation、请求、停止/删除意图及来源冲突继续拒绝；无 Kubernetes 直接读取回退，不放宽缓存健康证明。
  • 增加安全拒绝原因、阶段、关联 ID 和 assignment 版本日志；不记录 token、环境或请求正文。
  • 保持现有 Agent 协议和 Runtime 镜像；此次只更新 CM 镜像。
