检查标准与覆盖边界

  • 创建：实际到达 running，并具有匹配的运行绑定；HTTP 受理不等于创建完成。
  • 休眠：stopped_reason=idle_timeout，停止操作 phase=completed，运行绑定为 0。
  • 唤醒：新 runtime_generation 实际运行；12 个实例的工作区标记文件 SHA256 与休眠前一致。
  • 四类 Lite/Pro 共 8 条界面路径：休眠图标、键盘唤醒、处理中禁用、启动中切换；另测失败就地显示及重试、新代际不显示旧错误、手动停止/故障/启动中不冒充休眠。
  • 中、英、日、韩、德在 1440 / 1280 / 768 / 390 宽度检查，无整页横向溢出；减少动态效果模式下仍可操作。Pro 为模拟接口界面回归，本轮集群生命周期实测为 Lite。
  • 本轮创建使用真实 API，单实例唤醒同时检查修改后的真实界面按钮；原生 Agent 页面业务功能、模型回复及收费模型调用不在本轮断言范围。
