必须处理的缺陷

P1 · 重启提前增加 generation，停止必然被拒绝

四类均返回 HTTP 500：

failed to stop instance: runtime binding identity mismatch

实测实例 142–145：实例 generation=3、状态 stopped；绑定 generation=2、状态 running。restart 先执行 FenceRuntimeRestart，再由 stopInstance 重新读取已变更的实例，导致 stopV2Instance 代际校验失败。

修复方向：用原始 source generation 完成原生停止与绑定释放，停止证明成功后再进入新的启动代际；保留防止旧心跳复活的保护，不能直接放宽身份校验。

instance_service.go:2620 / 2281；instance_repository.go:831。此次仅分析和测试，未发布修复。

P1 · 休眠扫描跳周期，锁竞争造成继续延迟

修复方向：扫描只负责快速筛选、登记；由按类型隔离且有界的执行队列处理原生停止。慢停止不应阻塞其他类型的扫描；按实际 claim 时间和完成时间监测时效。
