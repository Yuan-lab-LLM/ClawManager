## 保留的安全约束

- 不放宽 Pod UID、槽位、代际、操作 ID、worker epoch、digest、工作区锁、隔离及存储不确定性检查。
- 活跃槽进程持有锁时 coordinator 仍转发请求；离线收尾不缓存跨所有权变更的账本。
- CM 持久化停止状态后才请求释放，原生释放完成后才清除绑定。
- 隔离验证池的 Pod API 对象消失只作为临时验证资源清理条件，不替代业务 C1 进程退出证明。
- Runtime 镜像只通过 CM 原生升级；OpenCode 缺少安全升级能力，维持拒绝及旧镜像。
