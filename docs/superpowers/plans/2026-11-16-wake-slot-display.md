# 唤醒槽位显示与 Skill Hub 精简

目标：正常启动预留及已核实身份的 starting/running 报告时差显示“启动”；移除 Skill Hub 正文介绍卡片。

实现：在 Runtime 库存只读投影增加 start_pending，保留 reconciliation_state、binding_confirmed、归属、代际和所有写入预检原值。仅在有效新鲜空观察对应创建中预留，或空观察早于新 binding 行，或完整匹配身份的 starting/running 报告时差时设置。前后端汇总与槽位视图共用此显示语义；未知、释放、不健康与真正归属冲突不覆盖。Skill Hub 只删除重复标题区，保留顶栏定位和工作流。
