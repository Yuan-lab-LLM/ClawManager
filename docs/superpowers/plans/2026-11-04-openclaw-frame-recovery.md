# OpenClaw 嵌入页空白恢复

用户已批准修复此前定位的嵌入页恢复缺口。沿用现有访问凭据与公共 hook，不延长 token、不绕过鉴权，不重启实例。

## 实现与验收

1. 在现有 `useInstanceDesktopAccess.test.mjs` 中添加失败回归：已建立页面报错后恢复、同源地址不变也能强制重载、页面持续空白时有限重试并结束、停止/卸载取消恢复。
2. 在测试节点使用缓存 Node 工具镜像运行这些测试，确认现有代码失败；不在本地执行测试。
3. 公共访问 hook 提供独立的 iframe 重载代次，确保相同 URL 的重载也真正发生；错误恢复重新申请凭据，退避重试最多 3 次，健康持续一段时间后才重置预算，人工重试重置预算。
4. 仅对同源 OpenClaw 嵌入页启用轻量页面检查，识别持续空白和确定的代理鉴权错误；不因单个工具请求失败、正常聊天内容出现错误字样或跨域不可读而重载。保留正常页面和输入，不按固定时间强制刷新。
5. 连接恢复期间显示状态，耗尽自动重试后显示失败提示与人工重试按钮。更新公共 hook 的两个 iframe 调用方使用重载代次。
6. 测试节点运行原有访问续期与新增恢复回归、TypeScript 检查、前端构建，验证实际浏览器中的空白恢复和重试终止。更新镜像保留当前正式计时后端、Runtime 配置和持久化数据。

本轮不改 CM 通知 WebSocket 或 OpenClaw 图像生成路由；它们是已记录的独立问题，不能混入本次空白恢复验收。
