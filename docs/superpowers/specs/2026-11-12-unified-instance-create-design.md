# 统一实例创建

用户已批准 `docs/uiux/2026-11-12-instance-create-preview.html` v4，并要求实现后部署到 10.130.81.54。

- `/instances/new` 单页完成创建。采用现有 Fluent 2 外壳；类型来自已启用的系统镜像设置，默认四种 Agent。取消镜像选择控件，自动使用对应模式的默认已启用镜像。
- Lite 不显示资源和初始化配置；Pro 保留 CPU/内存/存储、已有 GPU、存储类及专用配置能力和配额约束。镜像及运行模式能力边界不得放宽。
- 运行模式下方提供批量开关。单个显示名称；批量仅支持 Lite，显示前缀、2–100 个数量、起始序号。名称生成规则与既有批量接口一致，长度不超过 50。
- 负责人选填，空白时不提交 owner；描述选填。批量共享负责人、描述、环境变量、技能和可用的配置导入。
- 高级配置与实例信息同级左对齐，导入按钮置顶；选择后显示文件名，可更换和移除。配置导入沿用已有支持类型、文件格式和运行就绪等待；不支持的类型明确禁用，不伪造导入能力。
- 环境变量使用多行 KEY=value，支持注释和空行，校验名称与重复项，保留值中等号。右侧以 Key/Value 两列表格展示，敏感值遮蔽。
- 技能读取真实 attachable 列表，沿用有效/低风险和运行时兼容限制；勾选、检索、取消选择同步右侧；正式产品没有示例技能入口。
- 右侧展示类型、模式、名称、负责人、Pro 资源、环境变量与技能。批量部分失败保留逐项结果，不自动重建已创建项。配置导入失败提示已创建实例及重试导入，不再次创建。
- 列表原批量按钮和弹窗改为同一创建页面的批量入口；创建全部成功（包括最后一项重试成功）后返回 `/instances`，展示实例列表工作台，不停留在创建记录。部分失败和导入待处理时保留逐项处理入口。
- 所有用户态异步结果隔离账户切换与卸载；提交禁重入。窄屏自然重排，保留键盘、焦点和必要的错误恢复。
