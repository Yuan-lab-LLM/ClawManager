# Git 工作台与浏览器预览验收（2026-11-06）

Git 工作台补齐了未跟踪文本的真实行数与新文件差异、带行号的增删视图、图片预览、全部暂存和全部取消暂存。重命名批量操作包含原路径与新路径。提交缺少身份时自动打开仓库级姓名、邮箱表单，保存后保留提交信息，由用户再次点击提交。

身份只写入当前仓库，不修改全局 Git 配置。保存遵守 Git 的 `config.lock`，并保留仓库其他设置及签名配置。复杂的 Git worktree、配置 include 等布局会明确提示不支持身份编辑。大文件、超出读取预算或无法确定的统计不再伪装为 `+0 -0`；混合暂存状态也不会重复展示合计行数。图片显示工作区版本，并注明它可能不同于暂存内容。

浏览器入口使用现有管理端 HTTPS 主机与证书，通过不同端口区分原生应用和预览。Chrome 实测只在管理端确认一次证书，没有安装证书文件或 CA。预览在 credentialless iframe 内运行；外部打开使用管理端的独立预览页面。端口容量、备份与部署要求见 [浏览器端口说明](browser-origin-ports.md)。
