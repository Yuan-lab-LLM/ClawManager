# ClawManager 备份试行版使用手册

## 开始前

源端和目标端均从管理员导航进入 **备份**（`/admin/backups/records`）。演练使用两个独立的 Kubernetes namespace。若源和目标位于不同集群，页面交付步骤相同。

源端保存要备份的账号、实例和内容。目标端需要一个可登录的管理入口和一个已准备的空恢复业务库。恢复完成后，通过目标运行入口使用恢复的账号和实例。

平台为两端登记镜像摘要、独立数据库身份、存储和加密密钥引用。目标通过独立配置取得与源包匹配的解密材料。页面报告显示登记引用、实际检查结果和适用摘要。交付包中没有解密密钥。

## 1. 检查两端

1. 在两端点击 **检查试行就绪状态**，展开 **查看源和目标配置**，确认当前端、目标 namespace 和产物卷符合本次演练。
2. 同一集群首次准备时，先在源端点击 **准备试行环境**，等源端任务完成并生成试行密钥，再到目标端点击同一按钮。两端均已就绪时，跳过准备任务。跨集群时，由平台通过独立渠道把匹配的解密材料配置到目标端。
3. 需要留档或联系平台管理员时，点击 **下载环境检查报告**。检查源库只读权限、目标读写权限、独立读回、密钥和归档卷，以及本次所需的 Hermes 或工作区检查项。

## 2. 在源端备份

1. 点击 **创建试行备份** 可快速备份全部账号和实例。要明确指定会话和目录，请使用按范围备份。
2. 要指定内容，点击 **选择备份内容**。选择 **选择账号和实例** 或 **全部账号和实例**。按范围备份需包含至少一个启用的管理员。勾选实例会自动包含它的归属账号和配额。要备份管理员名下的实例，也勾选该实例。
3. 对已登记且可用的 Hermes 实例，勾选需要的会话。选择续会话会保留恢复所需的父会话。对已登记的工作区实例，浏览目录并选择本次需要备份的目录。
4. 点击 **创建所选备份**。等待任务成功并显示 **独立读回校验通过**。记下备份 ID、密文 SHA-256 和内容计数，然后点击 **下载备份交付包** 保存 `.tar`。

## 3. 在目标端导入并恢复

1. 在目标页点击 **导入备份交付包**，选择刚才下载的原始 `.tar`。导入后页面会填入备份 ID，并绑定源端的密文摘要。
2. 点击 **检查此备份**，核对页面显示的备份 ID、密文 SHA-256 和预期内容。确认显示 **产物读回和恢复内容预检通过**。
3. 点击 **恢复到隔离环境**。等恢复任务完成并显示 **独立读回校验通过**，记录恢复任务 ID 和内容计数。
4. 使用恢复的账号进入目标运行入口。核对该账号拥有的实例，按需启动实例，再检查聊天内容、顺序及工作区文件。恢复后的实例初始为停止状态。另一普通账号访问其他用户的实例、聊天或文件会被拒绝。

同集群跨 namespace 与跨集群均可使用这份 `.tar`。它包含恢复交接单、`<备份ID>.trial` 密文和 `<备份ID>.receipt` 回执。只有目标只读导入卷已拿到同一份原密文和回执时，才使用 **选择恢复交接单** 导入单独的 JSON。

## 常见问题

| 现象 | 怎么处理 |
| --- | --- |
| 备份或恢复按钮不可用 | 检查当前端的就绪和准备任务状态，按缺项联系平台管理员。 |
| 找不到某场会话或某个目录 | 检查是否选择了对应实例，再核对平台登记的可采集范围和该内容在源端是否可读。 |
| 导入后摘要不一致 | 核对源端下载的原始包、目标登记和备份 ID。用原始交付包重新预检。 |
| 目标已有业务数据 | 由平台准备新的空隔离目标，确认好环境后再恢复。 |
| Hermes 页面从父会话入口打开续会话 | 这是 Hermes 的会话展示方式。选定续会话的内容可在该入口核对。 |
| 需要复验或提报故障 | 保留备份 ID、任务 ID、摘要和配置检查报告。通过独立渠道交接测试账号凭据或密钥。 |
